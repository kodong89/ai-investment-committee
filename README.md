# AI 투자위원회

종목을 검색하면 다섯 명의 전설적 투자자 관점(AI)이 각자 **사자 / 중립 / 팔자** 의견과 **찬성 근거·반대 근거**를 내고, 리스크 매니저가 비중 한도를 정한 뒤 포트폴리오 매니저가 최종 방향을 결정합니다.

| 위원 | 관점 |
|---|---|
| 워런 버핏 | 경제적 해자, ROE, 내재가치, 10년 보유 |
| 찰리 멍거 | 사업의 질, 뒤집어 생각하기, 합리적 가격 |
| 벤 그레이엄 | 안전마진, PER·PBR·그레이엄 넘버 |
| 피터 린치 | PEG, 6가지 성장 범주, 텐배거 |
| 스탠리 드러켄밀러 | 유동성·금리 매크로, 추세, 비대칭 베팅 |

## 흐름
1. **데이터 수집**: Gemini + 구글 검색으로 현재가, PER, PBR, ROE, 부채비율, 성장률, 뉴스, 매크로를 정리합니다(출처 링크 표시).
2. **위원 5명 분석**: 각 철학의 기준을 수치에 대입해 결론, 이유, 찬성 근거, 반대 근거, 의견이 바뀌는 조건을 냅니다.
3. **리스크 매니저**: 변동성과 의견 분산을 보고 최대 비중(최대 25%)과 경고를 정합니다.
4. **포트폴리오 매니저**: 최종 행동, 목표 비중, 찬성·반대 논리 요약, 진입·손절·재검토 계획을 냅니다.

## 사용법
1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 API 키를 발급합니다.
2. 사이트의 **설정**에 키를 저장합니다. 키는 내 브라우저(localStorage)에만 저장되고 이 저장소에는 들어가지 않습니다.
3. 종목명이나 티커를 입력하고 **위원회 소집**을 누릅니다. 분석 1회에 API를 약 8번 호출합니다.

무료 한도에 걸리면 자동으로 기다렸다가 다시 시도합니다. 이미 분석한 종목은 상단 칩을 누르면 API 호출 없이 다시 볼 수 있습니다.

## 구성
서버 없이 `index.html` + `app.js` 정적 파일로 동작하며 GitHub Pages로 배포합니다.

> 각 위원은 실제 인물이 아니라 해당 투자자의 공개된 투자 철학을 따르는 AI 분석가입니다. 투자 권유가 아닙니다.
