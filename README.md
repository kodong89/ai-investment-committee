# AI 투자위원회 v2 — 스윙 투자 심사

종목을 검색하면 투자 대가 7인의 기준으로 채점해서 **점수, 판정, 매매 계획**을 보여줍니다. 대상은 수일~수개월 스윙 투자예요.

| 위원 | 역할 | 가중치 | 핵심 질문 |
|---|---|---|---|
| 스탠리 드러켄밀러 | 시장 방향 | 25% | 지금 돈이 이 종목으로 들어오는가? |
| 마크 미너비니 | 매수 타점 | 20% | 손실은 작고 상승 여력은 큰 타점인가? |
| 피터 린치 | 성장성 | 15% | 실적이 기대보다 빠르게 성장하는가? |
| 워런 버핏 | 기업 경쟁력 | 10% | 5년을 보유해도 괜찮은 기업인가? |
| 찰리 멍거 | 실패 가능성 | 10% | 어떤 이유로 큰돈을 잃을 수 있는가? |
| 벤저민 그레이엄 | 안전마진 | 10% | 가격이 가치 대비 매력적인가? |
| 폴 튜더 존스 | 리스크 관리 · 거부권 | 10% | 틀렸을 때 손실은 얼마인가? |

## 판단 방식
- **채점표 코드화**: 위원마다 배점이 있는 체크 항목(합 100점)이 있습니다. 추세 정렬, 52주 위치, 손익비, PEG, ROE, 유동비율, 그레이엄 넘버, VIX, 실적 발표일 같은 수치 항목은 **코드가 직접 판정**하고, 해자나 경영진 신뢰처럼 정성적인 항목만 AI가 판정합니다. 자료가 부족하면 점수가 50점 쪽으로 당겨집니다.
- **최종 점수** = 위원 점수 × 가중치의 합. 80점 이상은 매수 검토, 65~79점은 관심 종목, 65점 미만은 매수 제외입니다.
- **리스크 거부권**: 아래 중 하나라도 해당하면 최종 점수를 64점(매수 제외)으로 제한합니다.
  - 손익비 1.5 미만
  - 실적 발표 3일 이내
  - 시장이 하락장
  - VIX 30 초과
  - 폴 튜더 존스 관점에서 중대한 위험이 있다고 판단한 경우
- **손절가**: 2 ATR 방식과 지지선 − 0.5 ATR 방식을 비교해 더 가까운 쪽을 씁니다. 손익비는 저항선 기준으로 계산하고, 권장 비중 = 허용 손실(기본 2%) ÷ 손절폭(종목당 최대 기본 40%, 설정에서 변경)입니다.
- **찬반 토론**: 점수는 바꾸지 않고, 상승 논리를 반박하고 하락 시나리오를 점검합니다.

점수는 채점 기준을 얼마나 충족했는지를 뜻하며, 상승 확률이 아닙니다. 기준과 가중치는 초기 설계안이라 백테스트로 조정해야 합니다.

## 사용법
1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 키를 발급합니다.
2. 사이트의 **설정**에 키를 저장합니다. 키는 브라우저에만 저장됩니다.
3. 종목을 검색합니다.
   - 절약 모드: API 약 5회 호출 (시장 판단은 6시간 캐시)
   - 정밀 모드: 위원별로 따로 호출, 약 11회

> 각 위원은 실제 투자자 본인이 아니라 공개된 투자 철학을 바탕으로 한 AI 분석 역할입니다. 투자 권유가 아닙니다.
